# Hero automation tool icons

These genuine tool marks come from the upstream [Simple Icons project](https://github.com/simple-icons/simple-icons), pinned to commit `dc7b10662a0a2cfdfc9305e2a2b06c023c30724a`. They use the upstream path geometry, titles and 24×24 viewboxes unchanged. The only change is an explicit root `fill` using each icon’s upstream brand color: n8n `#EA4B71`, Make `#6D00CC`, Zapier `#FF4F00`.

`provenance.json` records the source URL and SHA-256 of every original and delivered file. `simple-icons-CC0-LICENSE.txt` preserves the upstream CC0 license; CC0 does not waive trademark rights. These icons identify third-party tools, without a claim of partnership or endorsement.

Official resources checked on 2026-10-11:

- [n8n brand guidelines](https://n8n.io/brandguidelines/): approved pink, dark and white colors; keep mark proportions, breathing room and do not distort the logo. The full logo guidance specifies a minimum width of 100px and discourages tilt.
- [Make press resources](https://www.make.com/en/press) and [logo manual](https://www.make.com/en/brand-guidelines.pdf): retain provided shapes, proportions and clear space; full logo minimum width is 96px.
- [Zapier trademark notice](https://zapier.com/legal/trademark-notice): identifies its tools and integrations on third-party websites without deceptive intent or confusion. Brand assets must follow its visual guidelines.

The hero tile artwork is illustrative. Keep SVG proportions intact, sufficient white inset around the mark, and do not add certification/partner badges.
